About LU Links

Built by students, for students — starting from zero.

💬 The root problem

Have you ever needed course materials — a Drive link, a Telegram group, an old exam — so you ask in a group chat… and everybody ghosts you? The biggest percentage is yes, you've been there. I faced the exact same challenge, and so have most students at the Lebanese University.

From that exact problem, LU Links was born.

🎯 What is LU Links

An initiative to gather all those useful links randomly scattered everywhere — Telegram groups, Google Drive folders, Classroom pages — and put them in one central place, easily reachable by all students.

We're starting from zero, with a clear goal: a single hub where any LU student can find what they need without begging in group chats.

⚙️ How it's built

A production-grade Go REST API backed by PostgreSQL — clean architecture, proper migrations, and a structured codebase designed to grow with the community.

The frontend is lightweight vanilla JS, no heavy frameworks, so pages load fast even on slow connections.

💚 Free, always

If I was a broke student looking for course materials, I wouldn't pay. So this stays free. LU Links exists because of the community — and it will always belong to it.

🚀 Help us build this from day one

We're literally starting from scratch — and that means every single link you submit matters. You know that Drive folder your friend shared at 2 AM before the exam? That Telegram group that saved your semester? Submit it here and help the next student find it without the struggle.
